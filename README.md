# No AIM テスト版

2人対戦の陣取りボードゲーム「No AIM」（仮タイトル）のテストプレイ用Webページです。

- 遊ぶ: https://tk-maui.github.io/No-Aim/

## 遊び方
- **1台で遊ぶ**: 1台の端末を2人で交代して遊びます。
- **2台で遊ぶ**: 1人が「部屋を作る」を押し（A）、表示されたリンクか4けたの部屋番号を相手に送ります。相手はリンクを開くか「部屋に参加する」で番号を入れます（B）。自分の番の端末だけが操作でき、相手の画面に反映されます。

## 記録
- プレイ中の記録は自動で残り、「行動ログ」「キャラ別集計」をCSVで保存できます（2台で遊ぶ場合はどちらの端末からでも保存できます）。
- ページを閉じても、次に開いたときに続きから再開できます。2台で遊んでいる途中で切れた場合も、同じ部屋に戻れます。
